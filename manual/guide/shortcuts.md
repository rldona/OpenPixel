# Keyboard shortcuts

With a keyboard, OpenPixel uses [Aseprite's shortcuts](https://www.aseprite.org/docs/keyboard-shortcuts/). The full list is also in the app: Edit › **Keyboard shortcuts** (⌘/), or hold **⌘** to see iPadOS's list.

## Tools

| Key | Tool |
|---|---|
| B / ⇧S | Pencil / spray |
| E | Eraser |
| G / ⇧G | Paint bucket / gradient |
| I | Eyedropper |
| L / ⇧L | Line / curve |
| U / ⇧U | Rectangle / ellipse |
| D / ⇧D | Contour / polygon |
| M / ⇧M | Rectangular / elliptical marquee |
| Q | Lasso |
| W | Magic wand |
| V / ⇧C | Move / slice |
| T | Text |
| ⌥ (hold) | Tap to pick a color |
| ⌃ (hold) | Stretch while moving a selection |
| [ ] | Smaller or bigger brush |
| X | Swap colors |

## Edit

| Key | Action |
|---|---|
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘X ⌘C ⌘V | Cut, copy, paste |
| ⌫ | Delete |
| ⌘T | Transform |
| ⇧H / ⇧V | Flip horizontally / vertically |
| ⇧R | Replace color |
| ⌘U | Hue/Saturation |
| ⌘B | New brush from selection |
| ⌘J / ⇧⌘J | New layer from selection / cut to new layer |

## Selection and transform

| Key | Action |
|---|---|
| ⌘A | Select all |
| ⌘D / ⇧⌘D | Deselect / reselect |
| ⇧⌘I | Invert selection |
| ↩ | Apply the transform or finish the shape |
| ⎋ | Cancel the transform or the shape |
| ← → ↑ ↓ | Nudge 1 px while transforming |

## Animation

| Key | Action |
|---|---|
| ↩ | Play or pause |
| , or ← / . or → | Previous / next frame |
| Home / End | First / last frame |
| ⌥N / ⌥⇧N | New frame / new empty frame |
| ⌥⌘T | New tag |
| ⇧N | New layer |
| ⇧X | Show or hide the layer |

## View

| Key | Action |
|---|---|
| ⌘+ / ⌘− | Zoom in / out |
| ⌘0 / ⌘1 | Fit to screen / actual size |
| ⌘' / ⇧⌘' | Pixel grid / grid |
| ⇥ | Focus mode |
| ⇧⌘E | Export |
| ⌘/ | Keyboard shortcuts |

## Gallery

| Key | Action |
|---|---|
| ⌘N | New sprite |
| ⌘F | Search |
| ⌘, | Preferences |
