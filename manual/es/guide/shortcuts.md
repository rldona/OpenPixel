# Atajos de teclado

Con teclado, OpenPixel usa los [atajos de Aseprite](https://www.aseprite.org/docs/keyboard-shortcuts/). La lista completa está también en la app: Editar › **Atajos de teclado** (⌘/), o mantén pulsado **⌘** para ver la lista de iPadOS.

## Herramientas

| Tecla | Herramienta |
|---|---|
| B / ⇧S | Lápiz / spray |
| E | Goma |
| G / ⇧G | Cubo de pintura / degradado |
| I | Cuentagotas |
| L / ⇧L | Línea / curva |
| U / ⇧U | Rectángulo / elipse |
| D / ⇧D | Contorno / polígono |
| M / ⇧M | Marco rectangular / elíptico |
| Q | Lazo |
| W | Varita mágica |
| V / ⇧C | Mover / slice |
| T | Texto |
| ⌥ (mantener) | Tocar para tomar un color |
| ⌃ (mantener) | Estirar al mover una selección |
| [ ] | Pincel más pequeño o más grande |
| X | Intercambiar colores |

## Edición

| Tecla | Acción |
|---|---|
| ⌘Z / ⇧⌘Z | Deshacer / rehacer |
| ⌘X ⌘C ⌘V | Cortar, copiar, pegar |
| ⌫ | Eliminar |
| ⌘T | Transformar |
| ⇧H / ⇧V | Voltear en horizontal / vertical |
| ⇧R | Reemplazar color |
| ⌘U | Tono/Saturación |
| ⌘B | Nuevo pincel con la selección |
| ⌘J / ⇧⌘J | Nueva capa con la selección / cortar a una capa nueva |

## Selección y transformación

| Tecla | Acción |
|---|---|
| ⌘A | Seleccionar todo |
| ⌘D / ⇧⌘D | Deseleccionar / volver a seleccionar |
| ⇧⌘I | Invertir selección |
| ↩ | Aplicar la transformación o terminar la forma |
| ⎋ | Cancelar la transformación o la forma |
| ← → ↑ ↓ | Mover 1 px mientras transformas |

## Animación

| Tecla | Acción |
|---|---|
| ↩ | Reproducir o pausar |
| , o ← / . o → | Frame anterior / siguiente |
| Inicio / Fin | Primer / último frame |
| ⌥N / ⌥⇧N | Nuevo frame / nuevo frame vacío |
| ⌥⌘T | Nuevo tag |
| ⇧N | Nueva capa |
| ⇧X | Mostrar u ocultar la capa |

## Vista

| Tecla | Acción |
|---|---|
| ⌘+ / ⌘− | Acercar / alejar |
| ⌘0 / ⌘1 | Ajustar a la pantalla / tamaño real |
| ⌘' / ⇧⌘' | Cuadrícula de píxeles / cuadrícula |
| ⇥ | Modo enfoque |
| ⇧⌘E | Exportar |
| ⌘/ | Atajos de teclado |

## Galería

| Tecla | Acción |
|---|---|
| ⌘N | Nuevo sprite |
| ⌘F | Buscar |
| ⌘, | Preferencias |
